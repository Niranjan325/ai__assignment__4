# Constraint Satisfaction Problems (CSP)

## Aim

To solve various Artificial Intelligence problems using Constraint Satisfaction Problem (CSP) techniques.

## Programs Included

### 1. Australia Map Coloring

Color the seven principal states and territories of Australia such that no two adjacent regions have the same color.

States:

* WA
* NT
* Q
* SA
* NSW
* V
* T

Technique Used:

* Backtracking CSP

---

### 2. Telangana Map Coloring

Assign colors to Telangana districts ensuring neighboring districts do not share the same color.

Technique Used:

* Constraint Satisfaction Problem
* Backtracking Search

---

### 3. Sudoku Solver

Solve a 9×9 Sudoku puzzle using CSP constraints.

Constraints:

* Unique values in every row
* Unique values in every column
* Unique values in every 3×3 grid

Technique Used:

* Backtracking CSP

---

### 4. Cryptarithmetic Puzzle

Solve the cryptarithmetic equation:

SEND + MORE = MONEY

Constraints:

* Each letter represents a unique digit.
* No leading digit can be zero.

Technique Used:

* CSP with Permutation Search

---

## Technologies Used

* Python 3
* Backtracking Algorithm
* Constraint Satisfaction Problems (CSP)

## Conclusion

This assignment demonstrates the use of CSP techniques in solving map coloring, Sudoku, and cryptarithmetic problems. The solutions satisfy all constraints while finding valid assignments efficiently.
